# 家庭维修账目

端口规划：`5114`

```bash
npm install
npm run dev
```

记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用 localStorage 保存数据。完工后的维修可以登记发票并走报销流水。

## 维修报销流水

- **完工登记**：维修完工时登记发票号、实付金额、垫付人，三者缺一不可；旧数据里已完工但没发票的维修可以补登。
- **报销流转**：提交申请先占用额度（申请中）→ 到账转为已报销 → 退回需填原因；撤销申请同样保留记录。退回与撤销都会恢复可报销额度。
- **额度约束**：同一笔维修的「申请中 + 已报销」永远不超过实付金额；换发票调低实付时也不能低于已占用与已报销合计。
- **发票唯一**：一张发票号同一时间只能挂在一笔维修上，杜绝一张发票拿去报两笔维修。
- **留痕可查**：换发票、退回、撤销都保留旧记录；有账目的维修不能删除。「报销流水」页可核对每笔记录与发票档案。
- **未完工不能报销**：报销入口只对已完工且已登记发票的维修开放。

## 目录结构（规则 / 存档 / 页面分层维护）

- `src/rules.js`：账目规则层 —— 纯函数，负责校验、状态流转与账目汇总
- `src/store.js`：存档层 —— localStorage 读写与旧数据迁移
- `src/pages/`：页面层 —— 维修事项页、报销流水页、共用视图工具
- `src/main.js`：入口，把存档、规则与页面装配起来
